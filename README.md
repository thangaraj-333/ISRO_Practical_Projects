# ISRO_Practical_Projects
ISRO & GATE related practical projects...

## The Sequential Plan:

>> **Phase 1:** Engineering Mathematics & Machine Learning

**GATE Focus:** Linear Algebra, Calculus, and Probability & Statistics.

**Practical Coupling:** Implement matrix operations from scratch in NumPy, visualize gradient descent paths, or code a Naive Bayes classifier.

**Outcome:** Solidify the mathematical proofs required for GATE numerical answer type (NAT) questions while understanding the mathematical engine powering ML models.

>> **Phase 2:** Algorithms, Data Structures & Python/C++

**GATE Focus:** Asymptotic analysis, divide & conquer, greedy methods, dynamic programming, trees, and graphs.

**Practical Coupling:** Solve algorithmic problems primarily in C/C++ (for direct pointer/memory mechanics tested in GATE) and rewrite key solutions in idiomatic Python.

**Outcome:** Master time and space complexity analysis while maintaining fluent syntax across both languages.

>> **Phase 3:** DBMS & Data Analysis

**GATE Focus:** Relational algebra, SQL queries, functional dependencies, normalization (BCNF, 3NF), and transaction concurrency control.

**Practical Coupling:** Spin up a local PostgreSQL/SQLite database, run analytical SQL queries, and connect it to a Python environment using pandas and SQLAlchemy for data transformation.

**Outcome:** Normalization and relational schema design stop feeling abstract, making complex join questions on GATE straightforward.
